# 🌿 Green Project — Автономный сайт девелоперской компании (Армения)

Полноценный, высокопроизводительный, представительский веб-сайт для застройщика **Green Project** (г. Ереван, Армения).

Проект создан на 100% автономным: работает локально на компьютере, не требует платных подписок, серверов, Vercel или сторонних бэкендов.

---

## 💎 Реализованный функционал и преимущества сайта

* 🌐 **100% Мультиязычность (HY / RU / EN)**: 157 параметров перевода без корявого машинного перевода (корректные топонимы: *ул. Царав Ахбюр*, *Нор-Норк*, *Аван*).
* 💱 **Мультивалютность (֏ AMD / $ USD)**: мгновенный пересчет всех цен и шагов калькулятора по актуальному курсу.
* ⚖️ **Калькулятор Закона о возврате подоходного налога РА (Ст. 156.1 НК РА)**:
  * Расчет стандартного аннуитетного платежа
  * Расчет компенсации из налога (до 500 000 ֏/мес)
  * Расчет фактического чистого платежа клиента
  * Расчет требуемой официальной брутто-зарплаты
  * Пресеты ведущих банков (Ameriabank, Inecobank, Ardshinbank, ACBA)
* 📐 **Интерактивные планировки с векторными схемами SVG**:
  * Студия (48.5 м²), 1-комн. (52.8 м²), 2-комн. (71.4 м²), 3-комн. (96.2 м²), Таунхаус (124.0 м²)
  * Подсветка комнат при наведении на экспликацию и наоборот
  * Кнопка быстрой брони конкретной планировки
* 🗺️ **Интерактивная карта объектов (Leaflet.js + SVG офлайн-фолбэк)**:
  * Маркеры объектов с зумом и карточками при клике
  * Если интернет недоступен, автоматически включается стилизованная векторная карта
* 📱 **Адаптивность и мобильный Drawer**:
  * Идеальный интерфейс на смартфонах (360px+) и 4K-экранах
  * Маска телефона Армении: `+374 (XX) XX-XX-XX`
* 💬 **Прямой захват лидов через WhatsApp и формы**:
  * Заявка на расчет ипотеки, каталог планировок, бронирование экскурсии

## 🚀 Как запустить и открыть проект

### Способ 1 (Самый быстрый):
Перейдите в папку:
`C:\Users\user\.gemini\antigravity\scratch\green-project-mockup`  
и **дважды кликните на `index.html`** — сайт мгновенно откроется в вашем браузере!

### Способ 2 (В Visual Studio Code с Live Server):
1. Откройте **Visual Studio Code**.
2. Нажмите **File** → **Open Folder...** и выберите:  
   `C:\Users\user\.gemini\antigravity\scratch\green-project-mockup`
3. Установите расширение **Live Server** (если еще не установлено).
4. Нажмите правой кнопкой мыши по `index.html` → **Open with Live Server**.
5. Страница откроется на `http://127.0.0.1:5500` с автообновлением при любых правках.
